# Orvio

Orvio is a web-based event management platform that allows organizers to create and manage events while enabling participants to discover, register for, and attend them.

## Features

- User Authentication
- Event Management
- Event Registration
- Attendance Tracking
- Feedback System
- Admin Dashboard

## Tech Stack

### Frontend
- Next.js
- Tailwind CSS
- shadcn/ui

### Backend
- FastAPI
- SQLAlchemy

### Database
- PostgreSQL
