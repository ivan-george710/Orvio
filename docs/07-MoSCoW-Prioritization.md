# MoSCoW Prioritization

This document prioritizes the Orvio product backlog using the MoSCoW method. The priorities guide delivery of a usable event-management platform while keeping lower-value enhancements for later iterations.

## Must Have

These capabilities are essential for the first usable release. Without them, users cannot safely discover, create, or register for events.

| ID | Requirement | Rationale |
|---|---|---|
| US-01 | View Profile | Users need access to their account information. |
| US-02 | Update Profile | Keeps user information accurate. |
| US-03 | Browse Events | Provides the core event-discovery experience. |
| US-05 | View Event Details | Gives participants the information needed to decide whether to attend. |
| US-06 | Create Event | Enables organizers to publish activities. |
| US-07 | Edit Event | Allows organizers to correct event information. |
| US-08 | Delete Event | Lets organizers remove unwanted events. |
| US-09 | View My Events | Lets organizers manage the events they own. |
| US-10 | Register for Event | Provides the main participant action. |
| US-12 | View My Registrations | Lets participants track their planned attendance. |
| US-19 | Responsive Design | Makes the platform usable on desktop and mobile devices. |
| US-20 | Deploy Application | Makes the completed system available to users. |

## Should Have

These features add substantial value but can follow the core release if time is limited.

| ID | Requirement | Rationale |
|---|---|---|
| US-04 | Search Events | Helps users quickly find relevant events. |
| US-11 | Cancel Registration | Gives participants flexibility when plans change. |
| US-13 | View Participants | Helps organizers prepare for their events. |
| US-14 | Approve/Reject Registration | Supports events that require organizer approval. |
| US-15 | Submit Feedback | Enables participants to share post-event feedback. |
| US-16 | View Feedback | Helps organizers improve future events. |

## Could Have

These features are desirable enhancements and should be implemented only after the Must and Should items are complete.

| ID | Requirement | Rationale |
|---|---|---|
| US-17 | Admin Manage Users | Improves moderation and user-account oversight. |
| US-18 | Admin Manage Events | Gives administrators broader content-management controls. |

## Won't Have in This Release

No backlog items are explicitly excluded from the current release. The Could Have items above may be deferred if the project schedule does not allow them.
