# User Stories

## Authentication

1. As a new user, I want to create an account so that I can use the platform.

2. As a registered user, I want to log in securely so that I can access my dashboard.

3. As a logged-in user, I want to log out so that my account remains secure.

## Profile Management

4. As a user, I want to view my profile so that I can see my personal information.

5. As a user, I want to update my profile details so that my information stays current.

## Event Management

6. As an organizer, I want to create an event so that I can host activities on the platform.

7. As an organizer, I want to upload an event banner so that my event is visually appealing.

8. As an organizer, I want to edit my event before approval so that I can correct mistakes.

9. As an organizer, I want to delete my own event so that I can remove unwanted events.

10. As an organizer, I want to submit my event for approval so that it can be reviewed by the administrator.

11. As an organizer, I want to view the status of my submitted events so that I know whether they are pending, approved, or rejected.

## Event Discovery

12. As a user, I want to browse approved events so that I can discover activities to attend.

13. As a user, I want to search for events so that I can quickly find events of interest.

14. As a user, I want to filter events by category so that I can easily find relevant events.

15. As a user, I want to view detailed event information so that I can decide whether to participate.

## Registration

16. As a user, I want to register for an event so that I can attend it.

17. As a user, I want to view all my registered events so that I can keep track of my participation.

18. As a user, I want to prevent duplicate registrations so that I do not accidentally register multiple times.

## Administration

19. As an administrator, I want to view all pending event requests so that I can review submissions.

20. As an administrator, I want to approve an event so that it becomes visible to all users.

21. As an administrator, I want to reject an event so that inappropriate or invalid events are not published.

22. As an administrator, I want to view all approved events so that I can manage published content.

23. As an administrator, I want to view all registered users so that I can monitor platform usage.

## Platform

24. As a user, I want the application to protect my personal data so that my information remains secure.

25. As a user, I want the platform to provide a responsive interface so that I can use it on desktop and mobile devices.
